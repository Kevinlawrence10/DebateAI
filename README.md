# 🧠 DebateAI

DebateAI is an AI-powered debate practice platform built with Streamlit. It allows users to participate in structured debates with an AI opponent and improve their argumentation, reasoning, and communication skills.

## Features

- 🎯 Topic selection
- ⚔️ FOR / AGAINST debate positions
- 🤖 AI-generated counterarguments
- 🎙️ Voice-to-text argument input
- 📊 Argument scoring
- 🧠 Reasoning and relevance analysis
- ⚠️ Logical fallacy detection
- 📝 Debate performance report
- 🔄 Multi-round debate system
- 🦙 Ollama integration for local AI responses

## Technologies Used

- Python
- Streamlit
- Faster-Whisper
- SpeechRecognition
- Ollama
- Llama 3.2
